# Guia prático de Markdown

## Títulos

```markdown
# Título principal
## Seção
### Subseção
```

## Ênfase

```markdown
**negrito**
*itálico*
~~tachado~~
```

Resultado: **negrito**, *itálico* e ~~tachado~~.

## Listas

```markdown
- Item
- Outro item

1. Primeiro
2. Segundo
```

## Checklist

```markdown
- [x] Tarefa concluída
- [ ] Tarefa pendente
```

## Links e imagens

```markdown
[GitHub](https://github.com)
![Descrição da imagem](https://exemplo.com/imagem.png)
```

## Tabela

```markdown
| Recurso | Uso |
|---|---|
| Git | Versionamento |

```

## Citação


## Código inline e bloco de código

Use `git status` para verificar o repositório.

````markdown
```bash
git status
git add .
```
````
