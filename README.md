## Sobre o projeto

Este projeto reúne exemplos práticos de Git, GitHub e Markdown, demonstrando organização de repositório, documentação, versionamento, colaboração por branches, issues e pull requests.

## Objetivos

- Praticar a criação e organização de um repositório público.
- Utilizar Markdown para produzir documentação clara.
- Registrar alterações por meio de commits objetivos.
- Simular um fluxo colaborativo com branch e pull request.
- Consolidar os principais comandos Git usados no dia a dia.

## Como executar o fluxo Git

### Clonar o repositório

```bash
git clone https://github.com/matheusflorindo32/desafio-github-markdown.git
cd desafio-github-markdown
```

### Criar uma branch

```bash
git checkout -b feature/minha-contribuicao
```

### Registrar alterações

```bash
git add .
git commit -m "docs: adiciona nova contribuição"
git push origin feature/minha-contribuicao
```

Depois, abra um pull request no GitHub comparando a sua branch com a `main`.
