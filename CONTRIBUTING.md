# Como contribuir

Obrigado pelo interesse em contribuir com este projeto.

## Fluxo recomendado

1. Faça um fork do repositório.
2. Clone o seu fork.
3. Crie uma branch descritiva.
4. Faça alterações pequenas e objetivas.
5. Revise a formatação Markdown.
6. Registre um commit claro.
7. Envie a branch para o GitHub.
8. Abra um pull request para a branch `main`.

```bash
git checkout -b docs/minha-contribuicao
git add .
git commit -m "docs: descreve a contribuição"
git push origin docs/minha-contribuicao
```

## Padrão de qualidade

- Escreva em português do Brasil.
- Evite erros ortográficos.
- Verifique links e blocos de código.
- Explique o propósito da alteração no pull request.
- Não inclua informações sensíveis.

## Mensagens de commit

Prefira mensagens como:

- `docs: adiciona exemplo de tabela`
- `docs: corrige instruções de clonagem`
- `fix: corrige link da documentação`

Ao contribuir, você concorda em seguir o [Código de Conduta](CODE_OF_CONDUCT.md).
